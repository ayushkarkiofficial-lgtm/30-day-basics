# AI Builder 30-Day Lab

This repo is for learning how to use Claude, Codex, and automation tools to build websites and workflows without studying programming languages deeply.

The goal is to build technical judgment:

- Explain what a website or automation does.
- Write clear instructions for AI agents.
- Review changed files without needing to code everything by hand.
- Test features manually.
- Keep prompts, decisions, mistakes, and reusable workflows organized.

## Folder Map

- `notes/` - Daily learning notes, decisions, prompts, and mistakes.
- `experiments/websites/` - Small website experiments and screenshots/notes.
- `experiments/automations/` - Automation maps, webhook tests, and workflow notes.
- `checklists/` - Reusable review and testing checklists.
- `templates/` - Copy/paste templates for specs, automation maps, and AI reviews.

## Daily Routine

Use this rhythm for each learning session:

1. Define today's outcome.
2. Write a short spec before asking AI to build.
3. Let Claude/Codex make a small change.
4. Ask it to explain the changed files in plain English.
5. Test the result manually.
6. Log what worked, what failed, and what to reuse.

## Rule

Do not memorize syntax. Learn the system shape, the workflow, and how to direct AI tools clearly.
